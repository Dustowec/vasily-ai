# ТЗ-025: Бэкапы

Дата: 2026-08-11
Статус: Draft
Фаза: 3

## Цель

Дать агенту простой локальный механизм байтовых бэкапов критичных данных,
не зависящий от шифрования и формата файлов.

## Минимальный scope

1. Новый модуль core/backup.py.
2. Класс BackupManager.
3. BackupManager принимает:
   - source_base: базовая папка;
   - source_paths: список файлов для бэкапа;
   - backup_root: папка для бэкапов.
4. create_backup() создаёт подпапку с меткой времени YYYYMMDD_HHMMSS.
5. Файлы копируются байт-в-байт с сохранением относительного пути от source_base.
6. Отсутствующие файлы пропускаются, ошибка не бросается.
7. list_backups() возвращает список папок бэкапов, новые сверху.

## Вне минимального scope

- восстановление из бэкапа;
- архивация zip;
- ротация и удаление старых бэкапов;
- облачные хранилища;
- шифрование.

## Acceptance criteria

1. create_backup() возвращает путь к новой папке.
2. Скопированные файлы идентичны исходным по байтам.
3. Отсутствующий исходный файл не ломает бэкап.
4. list_backups() сортирует папки по убыванию имени.
5. Существующие тесты остаются зелёными.
