# ТЗ-026: Локальный анализ crash-отчётов через LLM

Дата: 2026-08-11
Статус: Draft
Фаза: 3

## Цель

Дать агенту возможность анализировать локальные crash-отчёты через локальный LLM,
не отправляя данные во внешние сервисы.

## Минимальный scope

1. Новый модуль core/crash_analyzer.py.
2. Класс CrashAnalyzer принимает llm_client.
3. find_latest_report(log_dir) ищет последний crash_*.json в log_dir/crash_reports.
4. analyze_latest(log_dir):
   - если отчётов нет, возвращает None;
   - читает последний JSON-отчёт;
   - собирает короткий prompt из error.type, error.message и traceback;
   - вызывает llm.generate;
   - возвращает словарь с именем отчёта и текстом анализа.
5. В prompt не включаются полные recent_logs, чтобы не раздувать контекст.
6. Ошибки LLM не подавляются внутри CrashAnalyzer; вызывающий код сам решает,
   как их обрабатывать.

## Вне минимального scope

- автоматическое исправление ошибок;
- анализ сразу всех отчётов;
- отправка отчётов куда-либо;
- UI/API;
- сохранение результатов анализа на диск.

## Acceptance criteria

1. Если crash-отчётов нет, analyze_latest возвращает None.
2. Выбирается самый новый отчёт по имени файла.
3. Prompt содержит error.type и error.message.
4. Результат анализа содержит ответ LLM.
5. Существующие тесты остаются зелёными.
