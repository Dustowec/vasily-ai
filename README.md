# vasily-ai
Vasily AI — модульный AI-агент с асинхронным ядром и ReAct-циклом (рассуждение + действие). Подключается к локальной LLM через Ollama. Расширяется через плагины: генерация арт-промптов, веб-поиск (SearXNG), Danbooru. Двухуровневая память (hot/cold) с LLM-сжатием. Строгая обработка ошибок, защита от SSRF-атак, структурированные логи с ротацией.
